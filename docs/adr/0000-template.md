# ADR 0000: template

Copy this file for every decision that changes structure, a boundary, a storage choice, or a rule the tests enforce. One decision per file. Number sequentially. Never edit an accepted ADR; supersede it with a new one that names it.

## Status
Proposed | Accepted (date) | Superseded by ADR NNNN

## Context
What is true that forces a decision. Facts, constraints, the option space.

## Decision
One or two sentences. What we will do.

## Consequences
What becomes easier, what becomes harder, what we now have to keep doing. Include the cost honestly.
